# code-check Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `code-check` Claude Code plugin: four skills (`review-local`, `review-pr`, `address-comments`, `babysit-pr`) on top of a deterministic, tested Python 3.14 CLI, with a GitHub (`gh`) provider, a reviewer-agent panel, shadow-mode data capture, a Node installer and a README.

**Architecture:** A stdlib-only Python package (`codecheck`) exposes a JSON-in/JSON-out CLI that owns everything mechanical: sync, precheck, context building, diff anchoring, posting, approval policy, git, loop work-listing, CI fetching, telemetry. Skills (`SKILL.md`) and agents (`agents/*.md`) hold only judgment work and call the CLI for the rest. Loops run one headless `claude -p` process per PR (`run-pr`), so the user's session only sees short summaries; the same path serves remote agents.

**Tech Stack:** Python >= 3.14.10 (stdlib only at runtime; pytest + hypothesis for dev), `gh` CLI, `git`, Node >= 20 with `node:test` (no dependencies) for the installer, POSIX `sh` for the runtime bootstrap.

**Spec:** `docs/superpowers/specs/2026-11-12-code-check-design.md`

## Global Constraints

- Python floor is **3.14.10**; `doctor` warns (does not block) below it; CI runs on 3.14.10 or later.
- Runtime has **no third-party Python dependencies**; dev deps are `pytest` and `hypothesis` only.
- **CLI-first**: Phase 1 talks to GitHub only through the `gh` CLI. No MCP.
- All provider access goes through an injected `CommandRunner`; tests never touch the network.
- Severities are exactly `critical`, `warning`, `suggestion`. Comments are posted **inline**.
- Approval is `auto_approve and no critical and no warning`; a draft PR, an incomplete review, or a moved PR head is never approved/posted.
- **Never force-push.** Tests (when `address.test_command` is set) gate every push. Never auto-resolve pushback threads.
- Every skill run, local or remote, **fetches the latest remote base first** and compares against `<remote>/<base>` (never the local base branch); fetch failure marks output "base may be stale".
- `review-local` never posts anything.
- Loops: one PR at a time, at most `loop.max_prs_per_iteration` (default 5) per iteration; idle iterations spend zero LLM tokens.
- Models: aggregator `opus`, architect/pragmatist/skeptic `sonnet`, language experts `haiku`; all per-role/per-language configurable.
- Fifteen language experts: Python, JavaScript, TypeScript, Java, C#, C++, C, Go, Rust, PHP, Ruby, Swift, Kotlin, SQL, Shell.
- Shadow mode never changes behavior; it only records (secrets scrubbed, local store).
- Phase 1 deferrals: deep-reviewer implementation (slot only), eval replay harness (export format only).

## Review Focus

Input classes and failure modes the spec implies but does not enumerate; each has a pinned test in the owning task.

1. **Awkward diffs:** file paths with spaces, quotes or non-ASCII characters, CRLF content, a deleted line that starts with `-- ` (looks like a `---` header), and Unicode line separators inside file content must parse correctly and never shift line numbers (Task 6).
2. **Broken loop state:** a corrupt or truncated state file must not crash a loop; a PR that errors every time must not starve the rest of the queue; a new loop tick must not run while the previous one is still going (Tasks 9 and 17).
3. **Reviewer failure:** a reviewer that crashes, never writes its file, or writes invalid JSON must make the review *incomplete*, which can never auto-approve (Tasks 8 and 13).
4. **Moving target:** the PR head moving between review start and post must abort posting; a GitHub 422 on an inline anchor must degrade to a body-only review instead of losing the review (Tasks 11 and 13).
5. **Provider edge cases:** more than 100 review threads (pagination), `gh pr checks` exiting non-zero for failing/pending checks or reporting no checks, and fork-based PRs (cannot be pushed to in Phase 1) (Tasks 10, 11 and 14).

```python
"""Provider-independent data types shared by every layer."""

from dataclasses import asdict, dataclass
from enum import StrEnum


class Severity(StrEnum):
    CRITICAL = "critical"
    WARNING = "warning"
    SUGGESTION = "suggestion"

    @property
    def rank(self) -> int:
        return {"critical": 3, "warning": 2, "suggestion": 1}[self.value]

    @property
    def label(self) -> str:
        return self.value.capitalize()


@dataclass(frozen=True, slots=True)
class PRRef:
    repo: str
    number: int

    def __str__(self) -> str:
        return f"{self.repo}#{self.number}"

    @classmethod
    def parse(cls, text: str) -> PRRef:
        repo, sep, num = text.strip().rpartition("#")
        if not sep or repo.count("/") != 1 or not num.isdigit():
            raise ValueError(f"expected OWNER/REPO#NUMBER, got {text!r}")
        return cls(repo, int(num))


@dataclass(frozen=True, slots=True)
class PullRequest:
    ref: PRRef
    title: str
    body: str
    author: str
    base_ref: str
    head_ref: str
    head_sha: str
    is_draft: bool
    state: str  # "open" | "closed" | "merged"
    url: str
    is_cross_repo: bool = False


@dataclass(frozen=True, slots=True)
class ThreadComment:
    id: int
    author: str
    body: str
    created_at: str
    reactions: tuple[str, ...] = ()


@dataclass(frozen=True, slots=True)
class Thread:
    id: str
    path: str
    line: int | None
    is_resolved: bool
    is_outdated: bool
    comments: tuple[ThreadComment, ...]


@dataclass(frozen=True, slots=True)
class Check:
    name: str
    state: str  # "pass" | "fail" | "pending" | "skipped" | "cancelled"
    link: str = ""
    run_id: str | None = None


@dataclass(frozen=True, slots=True)
class Finding:
    file: str
    line: int
    severity: Severity
    category: str
    message: str
    suggestion: str | None = None
    reviewers: tuple[str, ...] = ()
    anchor: str = ""

    def to_dict(self) -> dict:
        d = asdict(self)
        d["severity"] = self.severity.value
        d["reviewers"] = list(self.reviewers)
        return d


@dataclass(frozen=True, slots=True)
class ReviewComment:
    path: str
    line: int
    side: str
    body: str


@dataclass(frozen=True, slots=True)
class Decision:
    event: str  # "APPROVE" | "COMMENT"

    posted: int
    degraded: bool = False
```

`src/codecheck/runner.py`:
```python
"""Thin subprocess abstraction; every external command goes through a CommandRunner."""

import subprocess
from collections.abc import Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import Protocol

from codecheck.errors import CodeCheckError


@dataclass(frozen=True, slots=True)
class CommandResult:
    returncode: int
    stdout: str = ""
    stderr: str = ""


class CommandError(CodeCheckError):
    def __init__(self, argv: Sequence[str], result: CommandResult) -> None:
        self.argv = list(argv)
        self.result = result
        super().__init__(f"{' '.join(argv[:4])} failed ({result.returncode}): {result.stderr.strip()[:500]}")


class CommandRunner(Protocol):
    def run(
        self,
        args: Sequence[str],
        *,
        input: str | None = None,
        cwd: Path | None = None,
        timeout: float | None = None,
    ) -> CommandResult: ...


class SubprocessRunner:
    def run(self, args, *, input=None, cwd=None, timeout=None) -> CommandResult:
        try:
            p = subprocess.run(
                list(args), input=input, cwd=cwd, capture_output=True,
                text=True, encoding="utf-8", errors="replace", timeout=timeout,
            )
        except FileNotFoundError as e:
            return CommandResult(127, "", str(e))
        except subprocess.TimeoutExpired:
            return CommandResult(124, "", f"timed out after {timeout}s")
        return CommandResult(p.returncode, p.stdout, p.stderr)


def run_checked(runner: CommandRunner, args: Sequence[str], **kwargs) -> CommandResult:
    result = runner.run(args, **kwargs)
    if result.returncode != 0:
        raise CommandError(args, result)
    return result
```

`tests/fakes.py`:
```python
"""Test doubles: FakeRunner (scripted commands) and, later, FakeProvider."""

from dataclasses import dataclass
from pathlib import Path

from codecheck.runner import CommandResult


@dataclass
class Call:
    argv: tuple[str, ...]
    input: str | None
    cwd: Path | None


class FakeRunner:
    def __init__(self) -> None:
        self._exact: dict[tuple[str, ...], list[CommandResult]] = {}
        self._prefix: list[tuple[tuple[str, ...], list[CommandResult]]] = []
        self.calls: list[Call] = []

    def on(self, *argv: str, stdout: str = "", stderr: str = "", returncode: int = 0) -> FakeRunner:
        self._exact.setdefault(tuple(argv), []).append(CommandResult(returncode, stdout, stderr))
        return self

    def on_prefix(self, *prefix: str, stdout: str = "", stderr: str = "", returncode: int = 0) -> FakeRunner:
        self._prefix.append((tuple(prefix), [CommandResult(returncode, stdout, stderr)]))
        return self

    def run(self, args, *, input=None, cwd=None, timeout=None) -> CommandResult:
        argv = tuple(args)
        self.calls.append(Call(argv, input, cwd))
        queue = self._exact.get(argv)
        if queue is None:
            for prefix, q in self._prefix:
                if argv[: len(prefix)] == prefix:
                    queue = q
                    break
        if queue is None:
            raise AssertionError(f"unexpected command: {argv}")
        return queue.pop(0) if len(queue) > 1 else queue[0]

    def argvs(self) -> list[tuple[str, ...]]:
        return [c.argv for c in self.calls]
```

```python
    )


@dataclass(frozen=True, slots=True)
class Config:
    provider: str = "github"
    base_branch: str = "auto"
    remote: str = "origin"
    state_dir: str = "~/.local/share/code-check/state"
    review: ReviewConfig = field(default_factory=ReviewConfig)
    loop: LoopConfig = field(default_factory=LoopConfig)
    models: ModelsConfig = field(default_factory=ModelsConfig)
    deep_reviewer: DeepReviewerConfig = field(default_factory=DeepReviewerConfig)
    shadow: ShadowConfig = field(default_factory=ShadowConfig)
    address: AddressConfig = field(default_factory=AddressConfig)
    run_pr: RunPrConfig = field(default_factory=RunPrConfig)


_FREEFORM = {("models", "per_language")}
_TRUE = {"1", "true", "yes", "on"}
_FALSE = {"0", "false", "no", "off"}


def expand_path(value: str) -> Path:
    return Path(value).expanduser()


def model_for(models: ModelsConfig, role: str, language: str | None = None) -> str:
    if role == "language_expert":
        if language and language in models.per_language:
            return models.per_language[language]
        return models.language_experts
    if role in ("aggregator", "reviewers", "deep"):
        return getattr(models, role)
    raise ConfigError(f"unknown model role {role!r}")


def _type_ok(default: object, value: object) -> bool:
    if isinstance(default, bool):
        return isinstance(value, bool)
    if isinstance(default, int):
        return isinstance(value, int) and not isinstance(value, bool)
    if isinstance(default, tuple):
        return isinstance(value, list) and all(isinstance(v, str) for v in value)
    return isinstance(value, type(default))


def _merge(base: dict, over: Mapping, path: tuple[str, ...] = ()) -> None:
    for key, value in over.items():
        here = (*path, key)
        if path in _FREEFORM:
            base[key] = value
            continue
        if key not in base:
            raise ConfigError(f"unknown config key: {'.'.join(here)}")
        if isinstance(base[key], dict):
            if not isinstance(value, Mapping):
                raise ConfigError(f"config key {'.'.join(here)} must be a table")
            _merge(base[key], value, here)
        elif not _type_ok(base[key], value):
            raise ConfigError(f"config key {'.'.join(here)} has the wrong type")
        else:
            base[key] = value


def _coerce(default: object, raw: str) -> object:
    if isinstance(default, bool):
        low = raw.strip().lower()
        if low in _TRUE:
            return True
        if low in _FALSE:
            return False
        raise ConfigError(f"cannot read {raw!r} as a boolean")
    if isinstance(default, int):
        try:
            return int(raw)
        except ValueError as e:
            raise ConfigError(f"cannot read {raw!r} as an integer") from e
    if isinstance(default, tuple):
        return [p.strip() for p in raw.split(",") if p.strip()]
    return raw


def _apply_env(data: dict, env: Mapping[str, str]) -> None:
    for name, raw in env.items():
        if not name.startswith("CODE_CHECK_"):
            continue
        parts = name.removeprefix("CODE_CHECK_").lower().split("__")
        node = data
        for part in parts[:-1]:
            node = node.get(part) if isinstance(node, dict) else None
            if not isinstance(node, dict):
                break
        else:
            leaf = parts[-1]
            if leaf in node and not isinstance(node[leaf], dict):
                current = node[leaf]
                node[leaf] = _coerce(tuple(current) if isinstance(current, list) else current, raw)


def _build(cls, data: Mapping):
    default = cls()
    kwargs = {}
    for f in fields(cls):
        dv = getattr(default, f.name)
        value = data[f.name]
        if is_dataclass(dv):
            kwargs[f.name] = _build(type(dv), value)
        elif isinstance(dv, tuple):
            kwargs[f.name] = tuple(value)
        else:
            kwargs[f.name] = value
    return cls(**kwargs)


def _read(path: Path) -> dict:
    try:
        return tomllib.loads(path.read_text(encoding="utf-8"))
    except FileNotFoundError:
        return {}
    except (tomllib.TOMLDecodeError, OSError) as e:
        raise ConfigError(f"cannot read {path}: {e}") from e


def load_config(repo_dir: Path, home: Path, env: Mapping[str, str]) -> Config:
    data = asdict(Config())
    _merge(data, _read(home / ".config" / "code-check" / "config.toml"))
    _merge(data, _read(repo_dir / ".code-check.toml"))
    _apply_env(data, env)
    return _build(Config, data)
```

Note: `asdict` keeps tuple defaults as tuples, TOML files supply lists (`_type_ok` expects a list for tuple defaults), and `_build` converts back to tuples. `_apply_env` therefore converts a list to a tuple before `_coerce` so it picks the comma-split branch.

```python
"""Git operations through a CommandRunner. This layer never force-pushes."""

from collections.abc import Sequence
from pathlib import Path

from codecheck.errors import GitError
from codecheck.runner import CommandResult, CommandRunner


class Git:
    def __init__(self, runner: CommandRunner, cwd: Path | str) -> None:
        self.runner = runner
        self.cwd = Path(cwd)

    def _run(self, *args: str) -> CommandResult:
        return self.runner.run(["git", "-c", "core.quotepath=false", *args], cwd=self.cwd)

    def _raw(self, *args: str) -> str:
        res = self._run(*args)
        if res.returncode != 0:
            raise GitError(f"git {' '.join(args[:3])} failed: {res.stderr.strip()}")
        return res.stdout

    def _out(self, *args: str) -> str:
        return self._raw(*args).strip()

    def fetch(self, remote: str, *refspecs: str) -> bool:
        return self._run("fetch", "--quiet", remote, *refspecs).returncode == 0

    def ref_exists(self, ref: str) -> bool:
        return self._run("rev-parse", "--verify", "--quiet", f"{ref}^{{commit}}").returncode == 0

    def default_branch(self, remote: str = "origin") -> str:
        res = self._run("symbolic-ref", "--quiet", "--short", f"refs/remotes/{remote}/HEAD")
        if res.returncode == 0 and res.stdout.strip():
            return res.stdout.strip().removeprefix(f"{remote}/")
        for candidate in ("main", "master"):
            if self.ref_exists(f"{remote}/{candidate}"):
                return candidate
        raise GitError("cannot determine the default branch; set base_branch in .code-check.toml")

    def rev_parse(self, ref: str) -> str:
        return self._out("rev-parse", ref)

    def merge_base(self, a: str, b: str) -> str:
        return self._out("merge-base", a, b)

    def diff(self, range_expr: str) -> str:
        return self._raw("diff", "--no-color", "--no-ext-diff", range_expr)

    def untracked(self) -> list[str]:
        out = self._raw("ls-files", "--others", "--exclude-standard", "-z")
        return [p for p in out.split("\0") if p]

    def local_diff(self, base_sha: str) -> str:
        parts = [self._raw("diff", "--no-color", "--no-ext-diff", base_sha)]
        for path in self.untracked():
            res = self._run("diff", "--no-color", "--no-index", "--", "/dev/null", path)
            if res.returncode in (0, 1):  # 1 just means "files differ"
                parts.append(res.stdout)
        return "".join(parts)

    def is_dirty(self) -> bool:
        return bool(self._out("status", "--porcelain"))

    def current_branch(self) -> str:
        return self._out("rev-parse", "--abbrev-ref", "HEAD")

    def head_sha(self) -> str:
        return self._out("rev-parse", "HEAD")

    def commit_time(self, ref: str) -> int:
        return int(self._out("log", "-1", "--format=%ct", ref))

    def behind_count(self, base_ref: str) -> int:
        return int(self._out("rev-list", "--count", f"HEAD..{base_ref}"))

    def remote_url(self, remote: str) -> str:
        return self._out("remote", "get-url", remote)

    def toplevel(self) -> Path:
        return Path(self._out("rev-parse", "--show-toplevel"))

    def commit(self, message: str, paths: Sequence[str]) -> str:
        if not paths:
            raise GitError("commit requires explicit paths; refusing to stage everything")
        self._raw("add", "--", *paths)
        self._raw("commit", "-m", message)
        return self.head_sha()

    def push(self, remote: str, branch: str) -> None:
        # Deliberately no force options anywhere in this layer.
        self._raw("push", remote, f"HEAD:refs/heads/{branch}")

    def worktree_add(self, path: Path, ref: str) -> None:
        self._raw("worktree", "add", "--detach", str(path), ref)

    def worktree_remove(self, path: Path) -> None:
        self._run("worktree", "remove", "--force", str(path))
        self._run("worktree", "prune")
```

```python
"""Fetch the latest remote base branch so comparisons use current upstream."""

import datetime
from dataclasses import dataclass

from codecheck.errors import SyncError
from codecheck.vcs.git import Git


@dataclass(frozen=True, slots=True)
class SyncResult:
    base_ref: str
    base_sha: str
    fresh: bool
    tip_time: int
    warning: str | None = None


def sync_base(git: Git, remote: str, base_branch: str = "auto") -> SyncResult:
    branch = git.default_branch(remote) if base_branch == "auto" else base_branch
    fresh = git.fetch(remote, branch)
    ref = f"{remote}/{branch}"
    if not git.ref_exists(ref):
        raise SyncError(f"base ref {ref} not found (fetch {'succeeded' if fresh else 'failed'})")
    sha = git.rev_parse(ref)
    tip = git.commit_time(ref)
    warning = None
    if not fresh:
        when = datetime.datetime.fromtimestamp(tip, datetime.UTC).strftime("%Y-%m-%d %H:%M UTC")
        warning = f"fetch of {ref} failed; using last-fetched {sha[:8]} (tip dated {when}); base may be stale"
```

```python
"""Parse unified diffs and anchor findings to lines a review comment can attach to."""

import re
from dataclasses import dataclass

_HUNK = re.compile(r"^@@ -(\d+)(?:,(\d+))? \+(\d+)(?:,(\d+))? @@")
_QUOTED = re.compile(r'^("(?:[^"\\]|\\.)*"|\S+) ("(?:[^"\\]|\\.)*"|\S+)$')


@dataclass(frozen=True, slots=True)
class DiffLine:
    kind: str  # "add" | "del" | "ctx"
    old: int | None
    new: int | None
    text: str


@dataclass(frozen=True, slots=True)
class FileDiff:
    path: str
    old_path: str
    status: str  # added | deleted | modified | renamed
    binary: bool
    lines: tuple[DiffLine, ...]
    patch: str

    def right_lines(self) -> dict[int, str]:
        return {ln.new: ln.text for ln in self.lines if ln.new is not None}


@dataclass(frozen=True, slots=True)
class Anchor:
    path: str
    line: int
    side: str = "RIGHT"
    relocated: bool = False


def _unquote(p: str) -> str:
    if len(p) >= 2 and p[0] == '"' and p[-1] == '"':
        body, raw, i = p[1:-1], bytearray(), 0
        while i < len(body):
            ch = body[i]
            if ch == "\\" and i + 1 < len(body):
                nxt = body[i + 1]
                if nxt in "01234567":
                    j, digits = i + 1, ""
                    while j < len(body) and len(digits) < 3 and body[j] in "01234567":
                        digits += body[j]
                        j += 1
                    raw.append(int(digits, 8))
                    i = j
                    continue
                raw.extend({"n": b"\n", "t": b"\t", '"': b'"', "\\": b"\\"}.get(nxt, nxt.encode()))
                i += 2
                continue
            raw.extend(ch.encode())
            i += 1
        return raw.decode("utf-8", "replace")
    return p


def _strip_prefix(p: str) -> str:
    p = _unquote(p.split("\t")[0])
    return p[2:] if p[:2] in ("a/", "b/") else p


def _header_paths(rest: str) -> tuple[str, str]:
    if '"' in rest:
        m = _QUOTED.match(rest)
        if m:
            return _strip_prefix(m.group(1)), _strip_prefix(m.group(2))
    n = (len(rest) - 5) // 2  # "a/P b/P"
    if n > 0 and rest[:2] == "a/" and rest[2 + n : 5 + n] == " b/" and rest[2 : 2 + n] == rest[5 + n :]:
        return rest[2 : 2 + n], rest[5 + n :]
    left, _, right = rest.partition(" b/")
    return left.removeprefix("a/"), right


def parse_diff(text: str) -> dict[str, FileDiff]:
    files: dict[str, FileDiff] = {}
    cur: dict | None = None
    rem_old = rem_new = old_n = new_n = 0

    def flush() -> None:
        if cur is None:
            return
        path = cur["old"] if cur["status"] == "deleted" else cur["new"]
        files[path] = FileDiff(
            path, cur["old"], cur["status"], cur["binary"], tuple(cur["lines"]), "\n".join(cur["raw"]) + "\n"
        )

    for raw in text.split("\n"):
        if cur is not None and (rem_old > 0 or rem_new > 0):
            cur["raw"].append(raw)
            c = raw[:1]
            if c == "+":
                cur["lines"].append(DiffLine("add", None, new_n, raw[1:]))
                new_n += 1
                rem_new -= 1
            elif c == "-":
                cur["lines"].append(DiffLine("del", old_n, None, raw[1:]))
                old_n += 1
                rem_old -= 1
            elif c == "\\":
                pass
            else:  # " " context, or a context line whose single space was stripped
                cur["lines"].append(DiffLine("ctx", old_n, new_n, raw[1:]))
                old_n += 1
                new_n += 1
                rem_old -= 1
                rem_new -= 1
            continue
        if raw.startswith("diff --git "):
            flush()
            old, new = _header_paths(raw[len("diff --git ") :])
            cur = {"old": old, "new": new, "status": "modified", "binary": False, "lines": [], "raw": [raw]}
            continue
        if cur is None:
            continue
        cur["raw"].append(raw)
        if raw.startswith("new file mode"):
            cur["status"] = "added"
        elif raw.startswith("deleted file mode"):
            cur["status"] = "deleted"
        elif raw.startswith("rename from "):
            cur["status"], cur["old"] = "renamed", _unquote(raw[len("rename from ") :])
        elif raw.startswith("rename to "):
            cur["new"] = _unquote(raw[len("rename to ") :])
        elif raw.startswith(("Binary files", "GIT binary patch")):
            cur["binary"] = True
        elif raw.startswith("--- "):
            p = _strip_prefix(raw[4:])
            if p != "/dev/null":
                cur["old"] = p
        elif raw.startswith("+++ "):
            p = _strip_prefix(raw[4:])
            if p != "/dev/null":
                cur["new"] = p
        elif m := _HUNK.match(raw):
            old_n, rem_old = int(m[1]), int(m[2]) if m[2] is not None else 1
            new_n, rem_new = int(m[3]), int(m[4]) if m[4] is not None else 1
    flush()
    return files


def anchor_finding(files: dict[str, FileDiff], path: str, line: int, *, max_distance: int = 3) -> Anchor | None:
    fd = files.get(path)
    if fd is None or fd.binary:
        return None
    right = fd.right_lines()
    if line in right:
        return Anchor(path, line)
    if not right:
        return None
    nearest = min(right, key=lambda n: (abs(n - line), n))
    if abs(nearest - line) <= max_distance:
        return Anchor(path, nearest, relocated=True)
    return None
```

```python
"""Finding schema validation, stable IDs and deterministic duplicate merging."""

import hashlib
from dataclasses import replace

from codecheck.core.diffmap import FileDiff
from codecheck.models import Finding, Severity


def normalize_text(text: str) -> str:
    return " ".join(text.lower().split())


def finding_id(f: Finding) -> str:
    key = f"{f.file}\0{normalize_text(f.anchor)}\0{normalize_text(f.message)}"
    return hashlib.sha256(key.encode()).hexdigest()[:12]


def _clean_path(path: str, root: str | None) -> str:
    path = path.strip()
    if root:
        path = path.removeprefix(root.rstrip("/") + "/")
    while path.startswith("./"):
        path = path[2:]
    return path


def validate_findings(raw: object, *, reviewer: str, root: str | None = None) -> tuple[list[Finding], list[str]]:
    if not isinstance(raw, list):
        return [], [f"{reviewer}: expected a JSON array of findings"]
    findings: list[Finding] = []
    errors: list[str] = []
    for i, item in enumerate(raw):
        where = f"{reviewer}[{i}]"
        if not isinstance(item, dict):
            errors.append(f"{where}: not an object")
            continue
        problems: list[str] = []
        file, line, sev = item.get("file"), item.get("line"), item.get("severity")
        message, category, suggestion = item.get("message"), item.get("category", "general"), item.get("suggestion")
        if not isinstance(file, str) or not file.strip():
            problems.append("file must be a non-empty string")
        if not isinstance(line, int) or isinstance(line, bool) or line < 1:
            problems.append("line must be a positive integer")
        if not isinstance(sev, str) or sev.lower() not in {s.value for s in Severity}:
            problems.append("severity must be critical, warning or suggestion")
        if not isinstance(message, str) or not message.strip():
            problems.append("message must be a non-empty string")
        if not isinstance(category, str) or not category.strip():
            category = "general"
        if suggestion is not None and not isinstance(suggestion, str):
            problems.append("suggestion must be a string")
        if problems:
            errors.extend(f"{where}: {p}" for p in problems)
            continue
        supplied = item.get("reviewers")
        who = tuple(supplied) if isinstance(supplied, list) and supplied and all(isinstance(r, str) for r in supplied) else (reviewer,)
        findings.append(
            Finding(
                file=_clean_path(file, root), line=line, severity=Severity(sev.lower()),
                category=category.strip(), message=message.strip(), suggestion=suggestion,
                reviewers=who,
            )
        )
    return findings, errors


def merge_exact_duplicates(findings: list[Finding]) -> list[Finding]:
    merged: dict[tuple, Finding] = {}
    for f in findings:
        key = (f.file, f.line, f.category, normalize_text(f.message))
        if key not in merged:
            merged[key] = f
            continue
        prev = merged[key]
        reviewers = tuple(dict.fromkeys((*prev.reviewers, *f.reviewers)))
        severity = max(prev.severity, f.severity, key=lambda s: s.rank)
        merged[key] = replace(prev, severity=severity, reviewers=reviewers, suggestion=prev.suggestion or f.suggestion)
    return list(merged.values())


def attach_anchors(findings: list[Finding], files: dict[str, FileDiff]) -> list[Finding]:
    out = []
    for f in findings:
        fd = files.get(f.file)
        out.append(replace(f, anchor=fd.right_lines().get(f.line, "") if fd else ""))
    return out
```

```python
from collections.abc import Sequence

from codecheck.models import Decision, Finding, Severity

_BLOCKING = (Severity.CRITICAL, Severity.WARNING)


def decide(findings: Sequence[Finding], *, auto_approve: bool, is_draft: bool, incomplete: bool = False) -> Decision:
    if is_draft:
        return Decision("COMMENT", "draft PRs are never approved")
    if incomplete:
        return Decision("COMMENT", "review incomplete: at least one reviewer failed or returned invalid output")
    if not auto_approve:
        return Decision("COMMENT", "auto_approve is off")
    blocking = [f for f in findings if f.severity in _BLOCKING]
    if blocking:
        return Decision("COMMENT", f"{len(blocking)} critical/warning finding(s) outstanding")
    return Decision("APPROVE", "no critical or warning findings")
```

```python
"""Language detection, ignore globs and reviewer-panel selection (no LLM)."""

import re
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from pathlib import PurePosixPath

LANGUAGES: dict[str, dict[str, tuple[str, ...]]] = {
    "python": {"ext": (".py", ".pyi"), "shebang": ("python",)},
    "javascript": {"ext": (".js", ".jsx", ".mjs", ".cjs"), "shebang": ("node",)},
    "typescript": {"ext": (".ts", ".tsx", ".mts", ".cts"), "shebang": ("ts-node", "tsx", "deno")},
    "java": {"ext": (".java",), "shebang": ()},
    "csharp": {"ext": (".cs",), "shebang": ()},
    "cpp": {"ext": (".cc", ".cpp", ".cxx", ".hpp", ".hh", ".hxx"), "shebang": ()},
    "c": {"ext": (".c", ".h"), "shebang": ()},
    "go": {"ext": (".go",), "shebang": ()},
    "rust": {"ext": (".rs",), "shebang": ()},
    "php": {"ext": (".php",), "shebang": ("php",)},
    "ruby": {"ext": (".rb",), "shebang": ("ruby",)},
    "swift": {"ext": (".swift",), "shebang": ("swift",)},
    "kotlin": {"ext": (".kt", ".kts"), "shebang": ()},
    "sql": {"ext": (".sql",), "shebang": ()},
    "shell": {"ext": (".sh", ".bash", ".zsh"), "shebang": ("sh", "bash", "zsh", "dash")},
}
CORE_REVIEWERS = ("architect", "pragmatist", "skeptic")


def detect_language(path: str, first_line: str = "") -> str | None:
    suffix = PurePosixPath(path).suffix.lower()
    for name, spec in LANGUAGES.items():
        if suffix and suffix in spec["ext"]:
            return name
    if first_line.startswith("#!"):
        tokens = [re.sub(r"[\d.]+$", "", t) for t in first_line[2:].replace("/", " ").split()]
        for name, spec in LANGUAGES.items():
            if any(t in spec["shebang"] for t in tokens):
                return name
    return None


def group_by_language(paths: Sequence[str], first_lines: Mapping[str, str] | None = None) -> dict[str, list[str]]:
    groups: dict[str, list[str]] = {}
    for p in paths:
        lang = detect_language(p, (first_lines or {}).get(p, ""))
        if lang:
            groups.setdefault(lang, []).append(p)
    return groups


def is_ignored(path: str, patterns: Sequence[str]) -> bool:
    p = PurePosixPath(path)
    return any(p.full_match(pat) for pat in patterns)


def filter_ignored(paths: Sequence[str], patterns: Sequence[str]) -> list[str]:
    return [p for p in paths if not is_ignored(p, patterns)]


@dataclass(frozen=True, slots=True)
class Panel:
    core: tuple[str, ...]
    languages: tuple[str, ...]
    deep: bool
    notes: tuple[str, ...] = ()

    @property
    def members(self) -> tuple[str, ...]:
        return (*self.core, *(f"lang-{lang}" for lang in self.languages), *(("deep-reviewer",) if self.deep else ()))


def select_panel(
    paths: Sequence[str],
    first_lines: Mapping[str, str] | None = None,
    *,
    deep_enabled: bool = False,
    deep_available: bool = False,
) -> Panel:
    languages = tuple(sorted(group_by_language(paths, first_lines)))
    notes: tuple[str, ...] = ()
    if deep_enabled and not deep_available:
        notes = ("deep-reviewer: enabled but unavailable, skipped",)
    return Panel(CORE_REVIEWERS, languages, deep_enabled and deep_available, notes)
```

```python
"""Split a large change into reviewable chunks without ever dropping a file."""

from collections.abc import Mapping


def chunk_files(sizes: Mapping[str, int], *, max_files: int, max_chars: int) -> list[list[str]]:
    chunks: list[list[str]] = []
    current: list[str] = []
    chars = 0
    for path, size in sizes.items():
        if current and (len(current) >= max_files or chars + size > max_chars):
            chunks.append(current)
            current, chars = [], 0
        current.append(path)
        chars += size
    if current:
        chunks.append(current)
    return chunks
```

```python
"""Persistent loop/review state, a cross-process lock, fingerprints and work selection."""

import contextlib
import hashlib
import json
import os
import time
from collections.abc import Callable, Sequence
from dataclasses import dataclass
from pathlib import Path

from codecheck.models import Check, PRRef, PullRequest, Thread


class StateStore:
    def __init__(self, path: Path) -> None:
        self.path = Path(path)

    def _load(self) -> dict:
        try:
            data = json.loads(self.path.read_text(encoding="utf-8"))
        except FileNotFoundError:
            return {}
        except (json.JSONDecodeError, OSError, UnicodeDecodeError):
            with contextlib.suppress(OSError):
                os.replace(self.path, self.path.with_suffix(".corrupt"))
            return {}
        return data if isinstance(data, dict) else {}

    def _write(self, data: dict) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        tmp = self.path.with_suffix(f".{os.getpid()}.tmp")
        tmp.write_text(json.dumps(data, sort_keys=True), encoding="utf-8")
        os.replace(tmp, self.path)

    def get(self, key: str, default=None):
        return self._load().get(key, default)

    def set(self, key: str, value) -> None:
        data = self._load()
        data[key] = value
        self._write(data)

    def delete(self, key: str) -> None:
        data = self._load()
        if data.pop(key, None) is not None:
            self._write(data)

    def incr(self, key: str) -> int:
        data = self._load()
        data[key] = int(data.get(key, 0)) + 1
        self._write(data)
        return data[key]


class FileLock:
    def __init__(self, path: Path, *, stale_after: float = 7200, now: Callable[[], float] = time.time) -> None:
        self.path, self.stale_after, self.now = Path(path), stale_after, now

    def acquire(self, _retry: bool = True) -> bool:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        try:
            fd = os.open(self.path, os.O_CREAT | os.O_EXCL | os.O_WRONLY)
        except FileExistsError:
            try:
                age = self.now() - self.path.stat().st_mtime
            except FileNotFoundError:
                return self.acquire(False) if _retry else False
            if age < self.stale_after or not _retry:
                return False
            self.path.unlink(missing_ok=True)
            return self.acquire(False)
        os.write(fd, str(os.getpid()).encode())
        os.close(fd)
        return True

    def release(self) -> None:
        self.path.unlink(missing_ok=True)


def local_fingerprint(merge_base: str, head: str, diff: str) -> str:
    return hashlib.sha256(f"{merge_base}\0{head}\0{diff}".encode()).hexdigest()[:16]


def actionable_threads(threads: Sequence[Thread], me: str) -> list[Thread]:
    return [
        t for t in threads
        if not t.is_resolved and not t.is_outdated and t.comments and t.comments[-1].author != me
    ]


@dataclass(frozen=True, slots=True)
class WorkItem:
    ref: PRRef
    fingerprint: str
    reason: str


def babysit_work(pr: PullRequest, threads: Sequence[Thread], checks: Sequence[Check], me: str) -> WorkItem | None:
    if pr.state != "open":
        return None
    actionable = actionable_threads(threads, me)
    failing = [c for c in checks if c.state == "fail"]
    if not actionable and not failing:
        return None
    parts = [
        pr.head_sha,
        *sorted(f"{t.id}:{t.comments[-1].id}" for t in actionable),
        *sorted(f"{c.name}={c.state}" for c in checks),
    ]
    fp = hashlib.sha256("\0".join(parts).encode()).hexdigest()[:16]
    bits = []
    if actionable:
        bits.append(f"{len(actionable)} thread{'s' if len(actionable) != 1 else ''}")
    if failing:
        bits.append(f"{len(failing)} failing check{'s' if len(failing) != 1 else ''}")
    return WorkItem(pr.ref, fp, ", ".join(bits))


def select_work(items: Sequence[WorkItem], state: StateStore, mode: str, limit: int) -> list[WorkItem]:
    fresh = [i for i in items if state.get(f"{mode}:{i.ref}") != i.fingerprint]
    return fresh[:limit]


def mark_processed(state: StateStore, mode: str, item: WorkItem) -> None:
    state.set(f"{mode}:{item.ref}", item.fingerprint)
```

```python
"""Decide, without any LLM call, whether there is anything worth reviewing."""

from collections.abc import Sequence
from dataclasses import dataclass

from codecheck.core.panel import filter_ignored
from codecheck.core.state import StateStore
from codecheck.models import PullRequest


@dataclass(frozen=True, slots=True)
class PrecheckResult:
    proceed: bool
    reason: str
    files: tuple[str, ...] = ()
    fingerprint: str = ""


def _skip(reason: str) -> PrecheckResult:
    return PrecheckResult(False, reason)


def precheck_pr(
    pr: PullRequest, files: Sequence[str], state: StateStore, *, ignore: Sequence[str], me: str, force: bool = False
) -> PrecheckResult:
    if pr.state != "open":
        return _skip(f"PR is {pr.state}")
    if pr.is_draft:
        return _skip("PR is a draft")
    if pr.author == me:
        return _skip("own PR: use address-comments instead")
    reviewable = filter_ignored(files, ignore)
    if not reviewable:
        return _skip("no reviewable files after ignore patterns")
    if not force and state.get(f"review:{pr.ref}") == pr.head_sha:
        return _skip(f"head {pr.head_sha[:8]} already reviewed")
    return PrecheckResult(True, "ok", tuple(reviewable), pr.head_sha)


def precheck_local(
    files: Sequence[str], fingerprint: str, state_key: str, state: StateStore, *, ignore: Sequence[str], force: bool = False
) -> PrecheckResult:
    if not files:
        return _skip("no changes against base")
    reviewable = filter_ignored(files, ignore)
    if not reviewable:
        return _skip("no reviewable files after ignore patterns")
    if not force and state.get(state_key) == fingerprint:
        return _skip("unchanged since last review")
    return PrecheckResult(True, "ok", tuple(reviewable), fingerprint)
```

```python
        raise NotImplementedError

        provider, _ = self.make_provider()
        assert isinstance(provider.whoami(), str) and provider.whoami()

        provider, ref = self.make_provider()
        pr = provider.get_pr(ref)
```

```python
"""GitHub adapter built on the `gh` CLI. No MCP, no stored credentials."""

import json
import re
from collections.abc import Sequence
from pathlib import Path

from codecheck.errors import ProviderError
from codecheck.models import Check, PRRef, PullRequest, Thread, ThreadComment
from codecheck.runner import CommandResult, CommandRunner

_REMOTE = re.compile(r"[:/]([^/:]+/[^/]+?)(?:\.git)?/?$")
_RUN_ID = re.compile(r"/actions/runs/(\d+)")
_BUCKET = {"pass": "pass", "fail": "fail", "pending": "pending", "skipping": "skipped", "cancel": "cancelled"}
_SCOPES = {"review-requested": "--review-requested=@me", "authored": "--author=@me"}
_PR_FIELDS = "number,title,body,author,baseRefName,headRefName,headRefOid,isDraft,state,url,isCrossRepository"
_LOG_TAIL_CHARS = 20_000

THREADS_QUERY = (
    "query($owner:String!,$name:String!,$number:Int!,$after:String){"
    "repository(owner:$owner,name:$name){pullRequest(number:$number){"
    "reviewThreads(first:100,after:$after){pageInfo{hasNextPage endCursor} "
    "nodes{id isResolved isOutdated path line originalLine "
    "comments(first:100){nodes{databaseId author{login} body createdAt reactions(first:50){nodes{content}}}}}}}}}"
)
RESOLVE_MUTATION = "mutation($id:ID!){resolveReviewThread(input:{threadId:$id}){thread{isResolved}}}"


def parse_remote_url(url: str) -> str | None:
    m = _REMOTE.search(url.strip())
    return m.group(1) if m else None


def _thread(n: dict) -> Thread:
    comments = tuple(
        ThreadComment(
            id=c["databaseId"],
            author=(c.get("author") or {}).get("login", "ghost"),
            body=c.get("body") or "",
            created_at=c.get("createdAt") or "",
            reactions=tuple(r["content"] for r in (c.get("reactions") or {}).get("nodes", [])),
        )
        for c in n["comments"]["nodes"]
    )
    return Thread(n["id"], n["path"], n.get("line") or n.get("originalLine"), n["isResolved"], n["isOutdated"], comments)


class GitHubProvider:
    name = "github"

    def __init__(self, runner: CommandRunner, cwd: Path | None = None) -> None:
        self.runner = runner
        self.cwd = cwd

    def _gh(self, *args: str, input: str | None = None, ok: Sequence[int] = (0,)) -> CommandResult:
        res = self.runner.run(["gh", *args], input=input, cwd=self.cwd)
        if res.returncode not in ok:
            raise ProviderError(f"gh {' '.join(args[:3])} failed ({res.returncode}): {res.stderr.strip()[:500]}")
        return res

    def _json(self, *args: str):
        return json.loads(self._gh(*args).stdout or "null")

    def whoami(self) -> str:
        return self._gh("api", "user", "--jq", ".login").stdout.strip()

    def get_pr(self, ref: PRRef) -> PullRequest:
        d = self._json("pr", "view", str(ref.number), "--repo", ref.repo, "--json", _PR_FIELDS)
        return PullRequest(
            ref=ref, title=d["title"], body=d.get("body") or "", author=(d.get("author") or {}).get("login", "ghost"),
            base_ref=d["baseRefName"], head_ref=d["headRefName"], head_sha=d["headRefOid"],
            is_draft=bool(d["isDraft"]), state=d["state"].lower(), url=d["url"],
            is_cross_repo=bool(d.get("isCrossRepository", False)),
        )

    def list_prs(self, scope: str, repos: Sequence[str]) -> list[PRRef]:
        if scope not in _SCOPES:
            raise ProviderError(f"unknown scope {scope!r}; use one of {sorted(_SCOPES)}")
        args = ["search", "prs", "--state", "open", _SCOPES[scope], "--limit", "50", "--json", "number,repository"]
        for repo in repos:
            args += ["--repo", repo]
        return [PRRef(i["repository"]["nameWithOwner"], i["number"]) for i in self._json(*args)]

    def list_changed_files(self, ref: PRRef) -> list[str]:
        out = self._gh("pr", "diff", str(ref.number), "--repo", ref.repo, "--name-only").stdout
        return [line for line in out.split("\n") if line]

    def fetch_refspec(self, ref: PRRef) -> tuple[str, str]:
        local = f"refs/code-check/pr/{ref.number}"
        return f"+pull/{ref.number}/head:{local}", local

    def repo_from_remote(self, url: str) -> str | None:
        return parse_remote_url(url)

    def clone_argv(self, repo: str, dest: str) -> list[str]:
        return ["gh", "repo", "clone", repo, dest]

    def list_threads(self, ref: PRRef) -> list[Thread]:
        owner, name = ref.repo.split("/", 1)
        threads: list[Thread] = []
        after: str | None = None
        while True:
            args = ["api", "graphql", "-f", f"query={THREADS_QUERY}", "-f", f"owner={owner}", "-f", f"name={name}",
                    "-F", f"number={ref.number}"]
            if after:
                args += ["-f", f"after={after}"]
            block = self._json(*args)["data"]["repository"]["pullRequest"]["reviewThreads"]
            threads += [_thread(n) for n in block["nodes"]]
            if not block["pageInfo"]["hasNextPage"]:
                return threads
            after = block["pageInfo"]["endCursor"]

    def get_checks(self, ref: PRRef) -> list[Check]:
        res = self._gh("pr", "checks", str(ref.number), "--repo", ref.repo, "--json", "name,bucket,link", ok=(0, 1, 8))
        if not res.stdout.strip():
            if res.returncode != 0 and "no checks reported" not in res.stderr:
                raise ProviderError(f"gh pr checks failed ({res.returncode}): {res.stderr.strip()[:500]}")
            return []
        checks = []
        for c in json.loads(res.stdout):
            m = _RUN_ID.search(c.get("link") or "")
            checks.append(Check(c["name"], _BUCKET.get(c.get("bucket"), "pending"), c.get("link") or "", m.group(1) if m else None))
        return checks

    def get_check_log(self, ref: PRRef, check: Check) -> str:
        if not check.run_id:
            return ""
        out = self._gh("run", "view", check.run_id, "--repo", ref.repo, "--log-failed").stdout
        return out[-_LOG_TAIL_CHARS:]
```

```python
    def post_review(
        self, ref: PRRef, head_sha: str, body: str, comments: Sequence[ReviewComment], decision: Decision
    ) -> PostResult:
        endpoint = f"repos/{ref.repo}/pulls/{ref.number}/reviews"
        argv = ["gh", "api", endpoint, "--method", "POST", "--input", "-"]

        def payload(text: str, inline: Sequence[ReviewComment]) -> str:
            return json.dumps({
                "commit_id": head_sha, "body": text, "event": decision.event,
                "comments": [{"path": c.path, "line": c.line, "side": c.side, "body": c.body} for c in inline],
            })

        res = self.runner.run(argv, input=payload(body, comments), cwd=self.cwd)
        if res.returncode == 0:
            return PostResult(len(comments))
        if not comments:
            raise ProviderError(f"posting review failed ({res.returncode}): {res.stderr.strip()[:500]}")
        folded = body + "\n\n---\n_The host rejected the inline anchors, so the findings are listed here instead._\n\n"
        folded += "\n\n".join(f"**`{c.path}:{c.line}`**\n{c.body}" for c in comments)
        retry = self.runner.run(argv, input=payload(folded, []), cwd=self.cwd)
        if retry.returncode != 0:
            raise ProviderError(f"posting review failed ({retry.returncode}): {retry.stderr.strip()[:500]}")
        return PostResult(0, degraded=True)

    def reply(self, ref: PRRef, thread: Thread, body: str) -> None:
        root = thread.comments[0].id
        self._gh("api", f"repos/{ref.repo}/pulls/{ref.number}/comments/{root}/replies", "--method", "POST", "-f", f"body={body}")

    def resolve(self, thread: Thread) -> None:
        self._gh("api", "graphql", "-f", f"query={RESOLVE_MUTATION}", "-f", f"id={thread.id}")

    def request_review(self, ref: PRRef, users: Sequence[str]) -> None:
        if not users:
            return
        args = ["api", f"repos/{ref.repo}/pulls/{ref.number}/requested_reviewers", "--method", "POST"]
        for user in users:
            args += ["-f", f"reviewers[]={user}"]
        self._gh(*args)
```

```python
"""Redact secrets before anything is written to the shadow store."""

import re

REDACTED = "[REDACTED]"
_PATTERNS: list[tuple[re.Pattern, str]] = [
    (re.compile(r"-----BEGIN [A-Z ]*PRIVATE KEY-----.*?-----END [A-Z ]*PRIVATE KEY-----", re.S), REDACTED),
    (re.compile(r"\bgh[pousr]_[A-Za-z0-9]{20,}"), REDACTED),
    (re.compile(r"\bgithub_pat_[A-Za-z0-9_]{20,}"), REDACTED),
    (re.compile(r"\bsk-ant-[A-Za-z0-9_-]{16,}"), REDACTED),
    (re.compile(r"\bAKIA[0-9A-Z]{16}\b"), REDACTED),
    (re.compile(r"(?i)\bauthorization\b\s*[:=]\s*(?:bearer\s+|basic\s+|token\s+)?\S+"), f"Authorization: {REDACTED}"),
    (re.compile(r"(?i)\bbearer\s+[A-Za-z0-9._~+/=-]{12,}"), f"Bearer {REDACTED}"),
    (re.compile(r"""(?i)\b(api[_-]?key|secret|token|password|passwd)\b\s*[:=]\s*["']?[^\s"']{8,}"""), rf"\1={REDACTED}"),
]


def scrub_text(text: str) -> str:
    for pattern, replacement in _PATTERNS:
        text = pattern.sub(replacement, text)
    return text


def scrub(obj):
    if isinstance(obj, str):
        return scrub_text(obj)
    if isinstance(obj, dict):
        return {k: scrub(v) for k, v in obj.items()}
    if isinstance(obj, list):
        return [scrub(v) for v in obj]
    return obj
```

```python
"""Append-only, schema-versioned JSONL store: one file per run."""

import json
import time
from collections.abc import Callable
from pathlib import Path

from codecheck.runids import check_run_id
from codecheck.shadow.scrub import scrub, scrub_text

SCHEMA = 1


class ShadowStore:
    def __init__(self, root: Path, now: Callable[[], float] = time.time) -> None:
        self.root = Path(root)
        self.now = now

    def _path(self, run_id: str, suffix: str) -> Path:
        return self.root / f"{check_run_id(run_id)}{suffix}"

    def append(self, run_id: str, record: dict) -> None:
        rec = scrub({"schema": SCHEMA, "ts": self.now(), "run_id": run_id, **record})
        path = self._path(run_id, ".jsonl")
        path.parent.mkdir(parents=True, exist_ok=True)
        with open(path, "a", encoding="utf-8") as fh:
            fh.write(json.dumps(rec, ensure_ascii=False, sort_keys=True) + "\n")

    def read(self, run_id: str) -> list[dict]:
        path = self._path(run_id, ".jsonl")
        if not path.exists():
            return []
        out = []
        for line in path.read_text(encoding="utf-8", errors="replace").splitlines():
            try:
                out.append(json.loads(line))
            except json.JSONDecodeError:
                continue
        return out

    def run_ids(self) -> list[str]:
        return sorted(p.stem for p in self.root.glob("*.jsonl")) if self.root.exists() else []

    def save_diff(self, run_id: str, diff: str) -> None:
        path = self._path(run_id, ".diff")
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(scrub_text(diff), encoding="utf-8")

    def read_diff(self, run_id: str) -> str:
        path = self._path(run_id, ".diff")
        return path.read_text(encoding="utf-8") if path.exists() else ""

    def runs_for_pr(self, pr: str) -> list[str]:
        return [
            rid for rid in self.run_ids()
            if any(r.get("type") == "run" and r.get("pr") == pr for r in self.read(rid))
        ]
```

```python
"""Turn a finished review into shadow-mode records. Recording never changes behavior."""

import hashlib
import json
from collections.abc import Mapping, Sequence
from dataclasses import asdict

from codecheck import __version__
from codecheck.config import Config
from codecheck.core.findings import finding_id
from codecheck.models import Decision, Finding
from codecheck.shadow.store import ShadowStore


def config_hash(cfg: Config) -> str:
    return hashlib.sha256(json.dumps(asdict(cfg), sort_keys=True, default=str).encode()).hexdigest()[:12]


def record_run(shadow: ShadowStore, meta: Mapping, diff: str, cfg: Config) -> None:
    run_id = meta["run_id"]
    shadow.append(run_id, {
        "type": "run", "skill": meta.get("skill"), "repo": meta.get("repo"), "pr": meta.get("pr"),
        "head_sha": meta.get("head_sha"), "mode": meta.get("mode"), "panel": list(meta["panel"]["members"]),
        "models": dict(meta.get("models", {})), "tool_version": __version__, "config_hash": config_hash(cfg),
        "tokens": None,
    })
    if diff:
        shadow.save_diff(run_id, diff)


def record_post(
    shadow: ShadowStore,
    meta: Mapping,
    *,
    reviewer_findings: Mapping[str, Sequence[Finding]],
    findings: Sequence[Finding],
    inline_ids: set[str],
    decision: Decision,
    incomplete: bool,
    dropped: Sequence[dict],
) -> None:
    run_id = meta["run_id"]
    for reviewer, items in reviewer_findings.items():
        for f in items:
            kept = any(k.file == f.file and abs(k.line - f.line) <= 2 for k in findings)
            shadow.append(run_id, {"type": "reviewer_finding", "reviewer": reviewer, "id": finding_id(f), "kept": kept, **f.to_dict()})
    for f in findings:
        fid = finding_id(f)
        shadow.append(run_id, {"type": "finding", "id": fid, "inline": fid in inline_ids, **f.to_dict()})
    shadow.append(run_id, {"type": "decision", "event": decision.event, "reason": decision.reason, "incomplete": incomplete})
    for d in dropped:
        shadow.append(run_id, {"type": "dropped", "detail": d})
```

```python
"""Comment, summary and local-report rendering. Hidden markers let shadow collection find our comments."""

import re
from collections import Counter
from collections.abc import Sequence

from codecheck.models import Decision, Finding, Severity

RUN_MARKER = "<!-- code-check:run:{} -->"
FINDING_MARKER = re.compile(r"<!-- code-check:finding:([0-9a-f]{12}) -->")


def marker(fid: str) -> str:
    return f"<!-- code-check:finding:{fid} -->"


def _fence(text: str) -> str:
    longest = max((len(m) for m in re.findall(r"`+", text)), default=0)
    return "`" * max(3, longest + 1)


def comment_body(f: Finding, fid: str, *, relocated: bool = False) -> str:
    lines = [f"**{f.severity.label}** · {f.category}", "", f.message]
    if f.suggestion:
        text = f.suggestion.rstrip("\n")
        fence = _fence(text)
        if relocated:
            lines += ["", "Suggested change:", fence, text, fence]
        else:
            lines += ["", f"{fence}suggestion", text, fence]
    if f.reviewers:
        lines += ["", f"<sub>code-check · {', '.join(f.reviewers)}</sub>"]
    lines.append(marker(fid))
    return "\n".join(lines)


def summary_body(
    run_id: str,
    findings: Sequence[Finding],
    unlisted: Sequence[Finding],
    decision: Decision,
    *,
    base_warning: str | None = None,
    failed_reviewers: Sequence[str] = (),
) -> str:
    counts = Counter(f.severity for f in findings)
    parts = [f"{counts[s]} {s.value}" for s in (Severity.CRITICAL, Severity.WARNING, Severity.SUGGESTION) if counts[s]]
    lines = ["## code-check review", "", ", ".join(parts) if parts else "No issues found."]
    if failed_reviewers:
        lines += ["", f"> Incomplete: no usable output from {', '.join(failed_reviewers)}; this review is not approved."]
    if base_warning:
        lines += ["", f"> {base_warning}"]
    if unlisted:
        lines += ["", "### Findings without an inline location", ""]
        lines += [f"- **{f.severity.label}** `{f.file}:{f.line}` {f.message}" for f in unlisted]
    lines += ["", RUN_MARKER.format(run_id)]
    return "\n".join(lines)


def render_local(new: Sequence[Finding], unchanged: int, base_warning: str | None = None) -> str:
    lines = [f"code-check local review: {len(new)} new, {unchanged} already shown"]
    if base_warning:
        lines.append(f"note: {base_warning}")
    for f in new:
        lines.append(f"[{f.severity.label}] {f.file}:{f.line} ({f.category}) {f.message}")
        if f.suggestion:
            lines += ["    suggestion:", *(f"      {s}" for s in f.suggestion.splitlines())]
    return "\n".join(lines)
```

```python
"""Command-line entry point. Every subcommand prints one JSON document on stdout."""

import argparse
import json
import os
import re
import sys
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from pathlib import Path

from codecheck import __version__, commands
from codecheck.config import Config, expand_path, load_config
from codecheck.core.state import StateStore

from codecheck.models import PRRef
from codecheck.providers import get_provider
from codecheck.providers.base import Provider
from codecheck.runids import check_run_id
from codecheck.runner import CommandRunner, SubprocessRunner
from codecheck.shadow.store import ShadowStore
from codecheck.vcs.git import Git

_PR_URL = re.compile(r"([^/\s]+/[^/\s]+)/pull/(\d+)")


@dataclass
class AppContext:
    config: Config
    runner: CommandRunner
    provider: Provider
    git: Git
    state: StateStore
    shadow: ShadowStore | None
    cwd: Path
    env: Mapping[str, str]

    def run_dir(self, run_id: str) -> Path:
        return expand_path(self.config.state_dir) / "runs" / check_run_id(run_id)

    def record(self, run_id: str, record: dict) -> None:
        if self.shadow is not None:
            self.shadow.append(run_id, record)

    def current_repo(self) -> str:
        repo = self.provider.repo_from_remote(self.git.remote_url(self.config.remote))
        if not repo:
            raise CodeCheckError(f"cannot work out the repository from remote {self.config.remote!r}")
        return repo

    def resolve_ref(self, text: str) -> PRRef:
        text = text.strip()
        if text.isdigit():
            return PRRef(self.current_repo(), int(text))
        if m := _PR_URL.search(text):
            return PRRef(m.group(1), int(m.group(2)))
        try:
            return PRRef.parse(text)
        except ValueError as e:
            raise CodeCheckError(str(e)) from None


def build_context(
    cwd: Path, env: Mapping[str, str], home: Path, runner: CommandRunner | None = None, provider: Provider | None = None
) -> AppContext:
    runner = runner or SubprocessRunner()
    git = Git(runner, cwd)
    try:
        cwd = git.toplevel()
        git = Git(runner, cwd)
    except CodeCheckError:
        pass  # not inside a repository; commands that need one will say so
    config = load_config(cwd, home, env)
    provider = provider or get_provider(config.provider, runner, cwd)
    shadow = ShadowStore(expand_path(config.shadow.store)) if config.shadow.enabled else None
    state = StateStore(expand_path(config.state_dir) / "state.json")
    return AppContext(config, runner, provider, git, state, shadow, cwd, env)


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="code-check", description="Deterministic PR review tooling")
    parser.add_argument("--version", action="version", version=f"code-check {__version__}")
    parser.add_argument("--cwd", type=Path, default=None, help="run as if started in this directory")
    sub = parser.add_subparsers(dest="command", required=True)
    for module in commands.ALL:
        p = sub.add_parser(module.NAME, help=module.HELP)
        module.add_arguments(p)
        p.set_defaults(func=module.run)
    return parser


def main(argv: Sequence[str] | None = None, *, ctx: AppContext | None = None, out=None) -> int:
    out = out or sys.stdout
    args = build_parser().parse_args(argv)
    try:
        ctx = ctx or build_context((args.cwd or Path.cwd()).resolve(), os.environ, Path.home())
        result = args.func(args, ctx)
    except CodeCheckError as e:
        print(json.dumps({"error": str(e)}), file=out)
        return 1
    print(json.dumps(result, indent=2, ensure_ascii=False), file=out)
    return 0


def main_entry() -> None:
    sys.exit(main())
```

```python
from codecheck.commands._common import finding_items, load_meta, write_json
from codecheck.core.findings import validate_findings

    p.add_argument("--run", required=True)


def run(args, ctx) -> dict:
    meta = load_meta(ctx, args.run)
    fdir = ctx.run_dir(args.run) / "findings"
    valid: dict[str, int] = {}
    invalid: dict[str, list[str]] = {}
    missing: list[str] = []
    for member in meta["panel"]["members"]:
        path = fdir / f"{member}.json"
        if not path.exists():
            missing.append(member)
            continue
        try:
            raw = json.loads(path.read_text(encoding="utf-8"))
        except (json.JSONDecodeError, UnicodeDecodeError) as e:
            (fdir / "invalid").mkdir(exist_ok=True)
            shutil.move(path, fdir / "invalid" / path.name)
            invalid[member] = [f"{member}: not valid JSON ({e})"]
            continue
        findings, errors = validate_findings(finding_items(raw), reviewer=member, root=meta["root"])
        path.write_text(json.dumps([f.to_dict() for f in findings], indent=2), encoding="utf-8")
        valid[member] = len(findings)
        if errors:
            invalid[member] = errors
    result = {"valid": valid, "invalid": invalid, "missing": missing, "incomplete": bool(invalid or missing)}
    write_json(ctx.run_dir(args.run) / "ingest.json", result)
    return result
```

```python
import json

from codecheck.commands._common import finding_items, load_meta, read_json
from codecheck.core.diffmap import anchor_finding, parse_diff
from codecheck.core.findings import attach_anchors, finding_id, merge_exact_duplicates, validate_findings
from codecheck.core.policy import decide
from codecheck.core.render import comment_body, render_local, summary_body
from codecheck.errors import CodeCheckError
from codecheck.models import PRRef, ReviewComment
from codecheck.shadow.recorder import record_post

NAME = "post"
HELP = "Post the aggregated review (PR mode) or print it (local mode)"


def add_arguments(p) -> None:
    p.add_argument("--run", required=True)


def _reviewer_findings(run_dir, ingest, meta) -> dict:
    out = {}
    for member in ingest["valid"]:
        raw = json.loads((run_dir / "findings" / f"{member}.json").read_text(encoding="utf-8"))
        out[member], _ = validate_findings(finding_items(raw), reviewer=member, root=meta["root"])
    return out


def run(args, ctx) -> dict:
    cfg = ctx.config
    meta = load_meta(ctx, args.run)
    run_dir = ctx.run_dir(args.run)
    if not (run_dir / "ingest.json").exists():
        raise CodeCheckError("run `code-check ingest` before `post`")
    ingest = read_json(run_dir / "ingest.json")
    agg_path = run_dir / "findings" / "aggregator.json"
    if not agg_path.exists():
        raise CodeCheckError("aggregator output missing: findings/aggregator.json")
    try:
        raw = json.loads(agg_path.read_text(encoding="utf-8"))
    except json.JSONDecodeError as e:
        raise CodeCheckError(f"aggregator output is not valid JSON: {e}") from e
    dropped = raw.get("dropped", []) if isinstance(raw, dict) else []
    findings, errors = validate_findings(finding_items(raw), reviewer="aggregator", root=meta["root"])
    if errors:
        raise CodeCheckError("aggregator output invalid: " + "; ".join(errors[:5]))
    diff_files = parse_diff((run_dir / "diff.patch").read_text(encoding="utf-8"))
    findings = merge_exact_duplicates(attach_anchors(findings, diff_files))
    findings.sort(key=lambda f: (-f.severity.rank, f.file, f.line))
    failed = sorted([*ingest["missing"], *ingest["invalid"]])
    incomplete = bool(ingest["incomplete"])

    if meta["mode"] == "local":
        seen = set(ctx.state.get(f"seen:{meta['local_key']}", []))
        new = [f for f in findings if finding_id(f) not in seen]
        ctx.state.set(f"seen:{meta['local_key']}", sorted({finding_id(f) for f in findings}))
        if not incomplete:
            ctx.state.set(meta["local_key"], meta["fingerprint"])
        unchanged = len(findings) - len(new)
        return {"mode": "local", "new_count": len(new), "unchanged_count": unchanged, "incomplete": incomplete,
                "failed_reviewers": failed, "text": render_local(new, unchanged, meta.get("base_warning"))}

    ref = PRRef.parse(meta["pr"])
    pr = ctx.provider.get_pr(ref)
    if pr.author == ctx.provider.whoami():
        raise CodeCheckError("refusing to post a review on your own PR")
    if pr.head_sha != meta["head_sha"]:
        return {"posted": False, "stale": True,
                "reason": f"PR head moved ({meta['head_sha'][:8]} -> {pr.head_sha[:8]}); re-run the review"}
    decision = decide(findings, auto_approve=cfg.review.auto_approve, is_draft=pr.is_draft, incomplete=incomplete)
    anchored, unlisted = [], []
    for f in findings:
        a = anchor_finding(diff_files, f.file, f.line)
        (anchored if a else unlisted).append((f, a))
    cap = cfg.review.max_inline_comments
    inline, overflow = anchored[:cap], anchored[cap:]
    comments = [ReviewComment(a.path, a.line, a.side, comment_body(f, finding_id(f), relocated=a.relocated)) for f, a in inline]
    not_inline = [f for f, _ in unlisted] + [f for f, _ in overflow]
    body = summary_body(meta["run_id"], findings, not_inline, decision,
                        base_warning=meta.get("base_warning"), failed_reviewers=failed)
    result = ctx.provider.post_review(ref, pr.head_sha, body, comments, decision)
    if not incomplete:
        ctx.state.set(f"review:{ref}", pr.head_sha)
    if ctx.shadow is not None:
        record_post(ctx.shadow, meta, reviewer_findings=_reviewer_findings(run_dir, ingest, meta), findings=findings,
                    inline_ids={finding_id(f) for f, _ in inline}, decision=decision, incomplete=incomplete, dropped=dropped)
    return {"posted": True, "degraded": result.degraded, "inline": len(comments), "unlisted": len(not_inline),
            "findings": len(findings), "decision": decision.event, "reason": decision.reason,
            "incomplete": incomplete, "failed_reviewers": failed, "base_warning": meta.get("base_warning"),
            "run_id": meta["run_id"]}
```

```python
import shutil
from pathlib import Path

from codecheck.commands._common import safe_repo
from codecheck.config import expand_path
from codecheck.errors import CodeCheckError
from codecheck.vcs.git import Git

NAME = "workspace"
HELP = "Return a safe directory to edit the PR branch in (in place, or an isolated worktree)"


def add_arguments(p) -> None:
    p.add_argument("--pr", required=True)


def _managed_clone(ctx, repo: str) -> Git:
    dest = expand_path(ctx.config.state_dir) / "repos" / repo.replace("/", "__")
    if not dest.exists():
        dest.parent.mkdir(parents=True, exist_ok=True)
        res = ctx.runner.run(ctx.provider.clone_argv(repo, str(dest)), cwd=ctx.cwd)
        if res.returncode != 0:
            raise CodeCheckError(f"could not clone {repo}: {res.stderr.strip()[:300]}")
    return Git(ctx.runner, dest)


def run(args, ctx) -> dict:
    cfg = ctx.config
    ref = ctx.resolve_ref(args.pr)
    pr = ctx.provider.get_pr(ref)
    if pr.is_cross_repo:
        raise CodeCheckError("fork-based PR: pushing to the contributor's fork is not supported in Phase 1")
    if pr.state != "open":
        raise CodeCheckError(f"PR is {pr.state}")
    here = safe_repo(ctx)
    if here == ref.repo and ctx.git.current_branch() == pr.head_ref:
        if ctx.git.is_dirty():
            raise CodeCheckError("working tree has uncommitted changes; commit or stash them first")
        return {"path": str(ctx.git.cwd), "created": False}
    base = ctx.git if here == ref.repo else _managed_clone(ctx, ref.repo)
    refspec, local_ref = ctx.provider.fetch_refspec(ref)
    if not base.fetch(cfg.remote, refspec):
        raise CodeCheckError(f"could not fetch the head of {ref}")
    path = expand_path(cfg.state_dir) / "worktrees" / f"addr-{ref.repo.replace('/', '__')}-{ref.number}"
    if path.exists():
        base.worktree_remove(path)
        shutil.rmtree(path, ignore_errors=True)
    path.parent.mkdir(parents=True, exist_ok=True)
    base.worktree_add_branch(path, f"code-check/pr-{ref.number}", local_ref)
    return {"path": str(path), "created": True, "git_dir": str(Path(base.cwd))}
```

```python
"""Match PR threads back to the findings we posted, and capture human feedback on them."""

from collections import Counter

from codecheck.core.render import FINDING_MARKER
from codecheck.models import PRRef
from codecheck.shadow.store import ShadowStore

REPLY_MARKER = "code-check:reply"


def collect_outcomes(provider, shadow: ShadowStore, ref: PRRef, me: str) -> dict:
    run_ids = shadow.runs_for_pr(str(ref))
    if not run_ids:
        return {"runs": 0, "outcomes": 0, "human_comments": 0}
    findings: dict[str, tuple[str, dict]] = {}
    for rid in run_ids:
        for rec in shadow.read(rid):
            if rec.get("type") == "finding":
                findings[rec["id"]] = (rid, rec)
    latest_run = run_ids[-1]
    outcomes = humans = 0
    for thread in provider.list_threads(ref):
        root = thread.comments[0]
        m = FINDING_MARKER.search(root.body)
        if m and m.group(1) in findings:
            rid, _ = findings[m.group(1)]
            replies = [
                {"author": c.author, "body": c.body}
                for c in thread.comments[1:]
                if c.author != me and REPLY_MARKER not in c.body
            ]
            shadow.append(rid, {
                "type": "outcome", "finding_id": m.group(1), "thread_id": thread.id,
                "resolved": thread.is_resolved, "outdated": thread.is_outdated,
                "replies": replies, "reactions": dict(Counter(root.reactions)),
            })
            outcomes += 1
        elif not m and root.author != me and not root.author.endswith("[bot]"):
            near = next(
                (fid for fid, (_, f) in findings.items()
                 if f["file"] == thread.path and thread.line is not None and abs(f["line"] - thread.line) <= 3),
                None,
            )
            shadow.append(latest_run, {
                "type": "human_comment", "thread_id": thread.id, "path": thread.path, "line": thread.line,
                "author": root.author, "body": root.body, "matches_finding": near,
            })
            humans += 1
    return {"runs": len(run_ids), "outcomes": outcomes, "human_comments": humans}
```

`src/codecheck/shadow/export.py`:
```python
"""Turn collected outcomes into a golden eval set (auto-labelled, for humans to review)."""

import json
from pathlib import Path

from codecheck.shadow.store import ShadowStore


def _label(outcome: dict | None) -> str:
    if outcome is None:
        return "unreviewed"
    if outcome["resolved"] or outcome["outdated"]:
        return "confirmed"
    if outcome["replies"]:
        return "disputed"
    return "no_signal"


def export_golden(shadow: ShadowStore, out_path: Path) -> int:
    rows = []
    for rid in shadow.run_ids():
        recs = shadow.read(rid)
        run = next((r for r in recs if r.get("type") == "run"), None)
        outcomes = {r["finding_id"]: r for r in recs if r.get("type") == "outcome"}
        humans = {r["thread_id"]: r for r in recs if r.get("type") == "human_comment"}
        diff = shadow.read_diff(rid)
        if run is None or not diff or not (outcomes or humans):
            continue
        matched = {h["matches_finding"] for h in humans.values() if h["matches_finding"]}
        findings = []
        for r in (x for x in recs if x.get("type") == "finding"):
            label = _label(outcomes.get(r["id"]))
            if r["id"] in matched and label in ("unreviewed", "no_signal"):
                label = "confirmed"
            findings.append({k: r[k] for k in ("id", "file", "line", "severity", "category", "message", "reviewers")} | {"label": label})
        rows.append({
            "run_id": rid, "repo": run.get("repo"), "pr": run.get("pr"), "head_sha": run.get("head_sha"),
            "tool_version": run.get("tool_version"), "models": run.get("models"), "diff": diff, "findings": findings,
            "misses": [{k: h[k] for k in ("path", "line", "author", "body")} for h in humans.values() if not h["matches_finding"]],
            "label_status": "auto",
        })
    Path(out_path).write_text("".join(json.dumps(r, ensure_ascii=False) + "\n" for r in rows), encoding="utf-8")
    return len(rows)
```

`src/codecheck/commands/shadow.py`:
```python
import json
import sys

from codecheck.errors import CodeCheckError
from codecheck.models import PRRef
from codecheck.shadow.collect import collect_outcomes
from codecheck.shadow.export import export_golden

NAME = "shadow"
HELP = "Shadow-mode data: collect human feedback, export a golden set, record verdicts"
VERDICTS = {"valid", "partial", "incorrect", "unclear", "preference", "out_of_scope"}


def add_arguments(p) -> None:
    sub = p.add_subparsers(dest="shadow_cmd", required=True)
    c = sub.add_parser("collect", help="match threads to posted findings and record human feedback")
    g = c.add_mutually_exclusive_group(required=True)
    g.add_argument("--pr")
    g.add_argument("--all", action="store_true")
    e = sub.add_parser("export-golden", help="write the auto-labelled golden set as JSONL")
    e.add_argument("--out", required=True)
    v = sub.add_parser("record-verdict", help="record address-comments verdicts (JSON list on stdin)")
    v.add_argument("--run", required=True)


def _prs_in_store(shadow) -> list[str]:
    seen = []
    for rid in shadow.run_ids():
        for rec in shadow.read(rid):
            if rec.get("type") == "run" and rec.get("pr") and rec["pr"] not in seen:
                seen.append(rec["pr"])
    return seen


def run(args, ctx) -> dict:
    if ctx.shadow is None:
        raise CodeCheckError("shadow mode is disabled (shadow.enabled = false)")
    if args.shadow_cmd == "export-golden":
        return {"exported": export_golden(ctx.shadow, args.out), "out": args.out}
    if args.shadow_cmd == "record-verdict":
        try:
            items = json.loads(sys.stdin.read())
        except json.JSONDecodeError as e:
            raise CodeCheckError(f"stdin is not valid JSON: {e}") from e
        for item in items:
            if not isinstance(item, dict) or item.get("verdict") not in VERDICTS:
                raise CodeCheckError(f"each item needs a verdict in {sorted(VERDICTS)}")
        for item in items:
            ctx.shadow.append(args.run, {"type": "verdict", **item})
        return {"recorded": len(items)}
    me = ctx.provider.whoami()
    if args.pr:
        return collect_outcomes(ctx.provider, ctx.shadow, ctx.resolve_ref(args.pr), me)
    results = []
    for pr in _prs_in_store(ctx.shadow):
        try:
            results.append({"pr": pr, **collect_outcomes(ctx.provider, ctx.shadow, PRRef.parse(pr), me)})
        except CodeCheckError as e:
            results.append({"pr": pr, "error": str(e)})
    return {"results": results}
```

```python
class HybridRunner:
    """Real git, scripted everything else."""

    def __init__(self, fake: FakeRunner) -> None:
        from codecheck.runner import SubprocessRunner

        self.fake = fake
        self.real = SubprocessRunner()

    def run(self, args, *, input=None, cwd=None, timeout=None):
        target = self.real if args and args[0] == "git" else self.fake
        return target.run(args, input=input, cwd=cwd, timeout=timeout)
```

```python
import json
import time

from codecheck.commands._common import safe_repo
from codecheck.commands.workspace import managed_clone
from codecheck.core.state import WorkItem, mark_processed
from codecheck.runids import new_run_id

NAME = "run-pr"
HELP = "Run one headless Claude process for one PR (review or babysit)"


def add_arguments(p) -> None:
    p.add_argument("--mode", choices=("review", "babysit"), required=True)
    p.add_argument("--pr", required=True)
    p.add_argument("--fingerprint", default=None, help="mark this work item processed when done")
    p.add_argument("--dry-run", action="store_true")


def parse_result(stdout: str, returncode: int, stderr: str) -> dict:
    """Normalise `claude -p --output-format json` output (key names confirmed by the Task 1 spike)."""
    try:
        data = json.loads(stdout)
    except (json.JSONDecodeError, TypeError):
        text = stdout.strip() or stderr.strip()
        if returncode == 124:
            return {"ok": False, "summary": f"timed out: {stderr.strip()}", "cost": None, "usage": None}
        why = "not json" if stdout.strip() else f"exit {returncode}"
        return {"ok": False, "summary": f"{why}: {text[-400:]}", "cost": None, "usage": None}
    result = str(data.get("result", ""))[-500:]
    ok = returncode == 0 and not data.get("is_error", False)
    return {"ok": ok, "summary": result if ok else f"error: {result or stderr.strip()[-400:]}",
            "cost": data.get("total_cost_usd"), "usage": data.get("usage")}


def run_one(ctx, mode: str, ref, fingerprint: str | None = None, dry_run: bool = False) -> dict:
    cfg = ctx.config.run_pr
    template = cfg.review_prompt if mode == "review" else cfg.babysit_prompt
    argv = [cfg.claude_bin, "-p", template.format(ref=ref), "--output-format", "json",
            "--permission-mode", cfg.permission_mode, "--permission-prompts", "none",
            "--allowedTools", ",".join(cfg.allowed_tools)]
    if dry_run:
        return {"pr": str(ref), "argv": argv}
    cwd = ctx.git.cwd if safe_repo(ctx) == ref.repo else managed_clone(ctx, ref.repo).cwd
    started = time.time()
    res = ctx.runner.run(argv, cwd=cwd, timeout=cfg.timeout_seconds, input="")  # input="" closes stdin: claude -p otherwise waits ~3s for it
    parsed = parse_result(res.stdout, res.returncode, res.stderr)
    duration = round(time.time() - started, 1)
    if fingerprint:
        mark_processed(ctx.state, mode, WorkItem(ref, fingerprint, ""))
    ctx.record(new_run_id(), {"type": "headless_run", "pr": str(ref), "mode": mode, "ok": parsed["ok"],
                              "cost_usd": parsed["cost"], "usage": parsed["usage"], "duration_s": duration})
    return {"pr": str(ref), "ok": parsed["ok"], "summary": parsed["summary"], "cost_usd": parsed["cost"], "duration_s": duration}


def run(args, ctx) -> dict:
    return run_one(ctx, args.mode, ctx.resolve_ref(args.pr), args.fingerprint, args.dry_run)
```

`src/codecheck/commands/loop.py`:
```python
from argparse import Namespace

from codecheck.commands import list_work
from codecheck.commands.run_pr import run_one
from codecheck.config import expand_path
from codecheck.core.state import FileLock, WorkItem, mark_processed
from codecheck.models import PRRef

NAME = "loop"
HELP = "One loop iteration: find PRs with new work, run each in its own headless process, one at a time"


def add_arguments(p) -> None:
    p.add_argument("--mode", choices=("review", "babysit"), required=True)
    p.add_argument("--repos", default="")
    p.add_argument("--dry-run", action="store_true")


def run(args, ctx) -> dict:
    lock = FileLock(expand_path(ctx.config.state_dir) / "locks" / f"{args.mode}.lock")
    if not lock.acquire():
        return {"skipped": True, "reason": "previous iteration still running"}
    try:
        work = list_work.run(Namespace(mode=args.mode, repos=args.repos), ctx)
        results = []
        for item in work["items"]:
            ref = PRRef.parse(item["pr"])
            try:
                results.append(run_one(ctx, args.mode, ref, item["fingerprint"], args.dry_run))
            except Exception as e:  # one broken PR must never stop the rest of the iteration
                if not args.dry_run:
                    mark_processed(ctx.state, args.mode, WorkItem(ref, item["fingerprint"], ""))
                results.append({"pr": item["pr"], "ok": False, "summary": f"error: {e}"})
        return {"mode": args.mode, "processed": len(results), "considered": work["considered"],
                "skipped": work["skipped"], "results": results}
    finally:
        lock.release()
```

```sh
#!/bin/sh
# Ensure a venv containing the code-check package exists. Idempotent and silent when current.
set -eu
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
DATA="${CODE_CHECK_HOME:-${CLAUDE_PLUGIN_DATA:-$HOME/.local/share/code-check}}"
VENV="$DATA/venv"
WANT="$(cat "$ROOT/VERSION" 2>/dev/null || echo dev)"
HAVE="$(cat "$DATA/installed-version" 2>/dev/null || echo none)"
if [ -x "$VENV/bin/python" ] && [ "$WANT" = "$HAVE" ]; then
  exit 0
fi
mkdir -p "$DATA"
if command -v uv >/dev/null 2>&1; then
  uv venv --python 3.14 --allow-existing "$VENV" >&2
  uv pip install --python "$VENV/bin/python" --quiet "$ROOT" >&2
else
  PY=""
  for c in python3.14 python3; do
    if command -v "$c" >/dev/null 2>&1 && "$c" -c 'import sys; sys.exit(0 if sys.version_info >= (3, 14) else 1)'; then
      PY="$c"
      break
    fi
  done
  if [ -z "$PY" ]; then
    echo "code-check needs Python >= 3.14 (3.14.10 or later recommended); install it or install uv" >&2
    exit 1
  fi
  "$PY" -m venv "$VENV" >&2
  "$VENV/bin/python" -m pip install --quiet "$ROOT" >&2
fi
printf '%s' "$WANT" > "$DATA/installed-version"
```

````markdown
# review-local

Reviews the current branch against `<remote>/<base>` (fetched first) and prints findings. It never posts to any pull request. Under `/loop` it spends no tokens while your work is unchanged.

`code-check` below means `"${CLAUDE_PLUGIN_ROOT}/bin/code-check"`. Every subcommand prints one JSON document.
````

```js
export function makeEnv() {
  const root = fs.mkdtempSync(path.join(os.tmpdir(), 'code-check-'));
  const home = path.join(root, 'home');
  fs.mkdirSync(home, { recursive: true });
  return {
    root,
    env: { ...process.env, HOME: home, CODE_CHECK_HOME: path.join(root, 'data'), CLAUDE_CONFIG_DIR: path.join(home, '.claude') },
  };
}

/** Scripted exec: records every call; flags choose which tools "exist" or fail. */
export function fakeExec({ python = 'Python 3.14.10', gh = true, claude = true, claudeFailsOn = [] } = {}) {
  const calls = [];
  const exec = (cmd, args = [], opts = {}) => {
    calls.push({ cmd, args, opts });
    const line = [cmd, ...args].join(' ');
    if (/^python/.test(cmd)) return cmd === 'python3.14' && python ? { status: 0, stdout: `${python}\n`, stderr: '' } : { status: 127, stdout: '', stderr: 'not found' };
    if (cmd === 'gh') return gh ? { status: 0, stdout: 'gh version 2.60\n', stderr: '' } : { status: 127, stdout: '', stderr: 'not found' };
    if (cmd === 'claude') {
      if (!claude) return { status: 127, stdout: '', stderr: 'not found' };
      return claudeFailsOn.some((s) => line.includes(s)) ? { status: 1, stdout: '', stderr: 'boom' } : { status: 0, stdout: '1.0.0\n', stderr: '' };
    }
    return { status: 0, stdout: 'ok\n', stderr: '' };
  };
  exec.calls = calls;
  exec.lines = () => calls.map((c) => [c.cmd, ...c.args].join(' '));
  return exec;
}
```

```js
export function realExec(cmd, args = [], opts = {}) {
  const r = spawnSync(cmd, args, { encoding: 'utf8', ...opts });
  if (r.error) return { status: r.error.code === 'ENOENT' ? 127 : 1, stdout: '', stderr: String(r.error.message) };
```

`installer/lib/doctor.js`:
```js
const RECOMMENDED = [3, 14, 10];
const FLOOR = [3, 14, 0];
const cmp = (a, b) => {
  for (let i = 0; i < 3; i += 1) if (a[i] !== b[i]) return a[i] - b[i];
  return 0;
};

export function parsePython(text) {
  const m = /Python (\d+)\.(\d+)\.(\d+)/.exec(text || '');
  return m ? m.slice(1).map(Number) : null;
}

export function findPython(exec) {
  for (const cmd of ['python3.14', 'python3', 'python']) {
    const r = exec(cmd, ['--version']);
    const version = r.status === 0 ? parsePython(r.stdout || r.stderr) : null;
    if (version && cmp(version, FLOOR) >= 0) return { cmd, version };
  }
  return null;
}

export function runDoctor({ exec }) {
  const checks = [];
  const py = findPython(exec);
  if (py) {
    const warn = cmp(py.version, RECOMMENDED) < 0;
    checks.push({
      name: 'python', ok: true, required: true, warn,
      detail: `${py.cmd} ${py.version.join('.')}` + (warn ? ` (upgrade to ${RECOMMENDED.join('.')} or later for security fixes)` : ''),
    });
  } else {
    checks.push({ name: 'python', ok: false, required: true, warn: false, detail: 'Python >= 3.14 not found (3.14.10 or later recommended)' });
  }
  for (const [name, cmd, args, required] of [
    ['git', 'git', ['--version'], true],
    ['gh', 'gh', ['--version'], true],
    ['gh auth', 'gh', ['auth', 'status'], false],
    ['claude', 'claude', ['--version'], false],
  ]) {
    const r = exec(cmd, args);
    checks.push({ name, ok: r.status === 0, required, warn: false, detail: ((r.stdout || r.stderr).trim().split('\n')[0]) || '' });
  }
  return { ok: checks.every((c) => c.ok || !c.required), checks };
}

export function formatDoctor(result) {
  return result.checks
    .map((c) => {
      const tag = c.ok ? (c.warn ? '[warn]' : '[ ok ]') : c.required ? '[FAIL]' : '[skip]';
      return `${tag} ${c.name}${c.detail ? `: ${c.detail}` : ''}`;
    })
    .join('\n');
}
```

```js
function copyPayload(src, dest) {
  fs.rmSync(dest, { recursive: true, force: true });
  fs.mkdirSync(dest, { recursive: true });
  for (const item of PAYLOAD) {
    const from = path.join(src, item);
    if (fs.existsSync(from)) {
      fs.cpSync(from, path.join(dest, item), {
        recursive: true,
        filter: (p) => !p.includes('__pycache__') && !p.endsWith('.egg-info'),
      });
    }
  }
  for (const f of ['bin/code-check', 'hooks/ensure-runtime.sh']) {
    const p = path.join(dest, f);
    if (fs.existsSync(p)) fs.chmodSync(p, 0o755);

}

function copyMode(paths, stage) {
  const skillsRoot = path.join(paths.claudeDir, 'skills');
  const agentsRoot = path.join(paths.claudeDir, 'agents');
  fs.mkdirSync(skillsRoot, { recursive: true });
  fs.mkdirSync(agentsRoot, { recursive: true });
  const files = [];
  for (const name of fs.readdirSync(path.join(stage, 'skills'))) {
    const dest = path.join(skillsRoot, name);
    fs.rmSync(dest, { recursive: true, force: true });
    fs.mkdirSync(dest, { recursive: true });
    const text = fs
      .readFileSync(path.join(stage, 'skills', name, 'SKILL.md'), 'utf8')
      .replaceAll('${CLAUDE_PLUGIN_ROOT}', stage)
      .replaceAll('code-check:', '');
    fs.writeFileSync(path.join(dest, 'SKILL.md'), text);
    files.push(dest);
  }
  for (const f of fs.readdirSync(path.join(stage, 'agents'))) {
    const dest = path.join(agentsRoot, f);
    fs.copyFileSync(path.join(stage, 'agents', f), dest);
    files.push(dest);
  }
  return files;
}

export function install({ exec = realExec, env = process.env, log = () => {} } = {}) {
  const paths = resolvePaths(env);
  const doctor = runDoctor({ exec });
  const failed = doctor.checks.filter((c) => c.required && !c.ok);
  if (failed.length) throw new Error(`prerequisites missing: ${failed.map((c) => `${c.name} (${c.detail})`).join('; ')}`);
  for (const c of doctor.checks.filter((x) => x.warn)) log(`warning: ${c.name}: ${c.detail}`);

  const stage = stageDir(paths);
  copyPayload(paths.pluginSrc, stage);
  const childEnv = { ...env, CODE_CHECK_HOME: paths.dataDir };
  const runtime = exec('sh', [path.join(stage, 'hooks', 'ensure-runtime.sh')], { env: childEnv });
  if (runtime.status !== 0) throw new Error(`runtime setup failed: ${(runtime.stderr || '').trim()}`);
  const gen = exec(path.join(paths.dataDir, 'venv', 'bin', 'python'), ['-m', 'codecheck', 'gen-agents', '--out', path.join(stage, 'agents')], { env: childEnv });
  if (gen.status !== 0) log('warning: could not apply configured models to the agents; using defaults');

  let mode = 'copy';
  let files = [];
  if (doctor.checks.find((c) => c.name === 'claude')?.ok) {
    exec('claude', CLAUDE_CMDS.uninstall);
    exec('claude', CLAUDE_CMDS.marketplaceRemove);
    const add = exec('claude', CLAUDE_CMDS.marketplaceAdd(stage));
    const done = add.status === 0 ? exec('claude', CLAUDE_CMDS.install) : add;
    if (done.status === 0) mode = 'plugin';
    else log(`claude plugin commands failed; copying skills and agents into ${paths.claudeDir} instead`);
  } else {
    log(`claude not found on PATH; copying skills and agents into ${paths.claudeDir}`);
  }
  if (mode === 'copy') files = copyMode(paths, stage);

  const version = fs.readFileSync(path.join(stage, 'VERSION'), 'utf8').trim();
  fs.writeFileSync(path.join(paths.dataDir, 'receipt.json'), JSON.stringify({ version, mode, stage, files }, null, 2));
  return { mode, stage, files, version };
}
```

```js
export function uninstall({ exec = realExec, env = process.env, log = () => {}, purgeData = false } = {}) {
  const paths = resolvePaths(env);
  const receiptPath = path.join(paths.dataDir, 'receipt.json');
  let receipt = null;
  try {
    receipt = JSON.parse(fs.readFileSync(receiptPath, 'utf8'));
  } catch {
    log('no install receipt found; removing what can be found');
  }
  if (!receipt || receipt.mode === 'plugin') {
    exec('claude', CLAUDE_CMDS.uninstall);
    exec('claude', CLAUDE_CMDS.marketplaceRemove);

  if (purgeData) for (const d of ['shadow', 'state']) fs.rmSync(path.join(paths.dataDir, d), { recursive: true, force: true });
  return { mode: receipt?.mode ?? 'unknown' };
}
```

````markdown
# code-check

Review code and deal with review comments on pull requests, from inside Claude Code.

`code-check` is a plugin with four skills on top of a deterministic Python CLI. Everything mechanical (git, the `gh` CLI, fetching and posting comments, diff anchoring, the approval policy, loop bookkeeping) is ordinary tested code. Agents are used only for judgment: reviewing code, weighing review comments, diagnosing CI failures, writing fixes.

| Skill | What it does |
|---|---|
| `review-local` | Reviews your own branch (committed and uncommitted) against the freshly fetched remote base and prints the findings. Never posts. |
| `review-pr` | Reviews a teammate's PR and posts one inline review. With no argument it works your review-requested queue, at most 5 PRs per run, one at a time. |
| `address-comments` | On your own PR: checks each unresolved thread critically, fixes what is valid, pushes back with evidence on what is not, pushes behind a test gate, replies, resolves fixed threads, re-requests review. |
| `babysit-pr` | `address-comments` plus failing CI checks, across your PRs, designed to run under `/loop`. |

Findings are **Critical**, **Warning** or **Suggestion** and are posted inline on the changed lines. A panel of reviewers works on each change: up to 15 language experts (only for languages present in the diff), an architecture reviewer, a pragmatic reviewer and a skeptic, with an optional slot for a "deep" reviewer backed by your own knowledge sources. An Opus aggregator verifies every Critical and Warning against the code before anything is posted.

```
precheck (no LLM) → fetch latest base → context → reviewer panel (parallel) → ingest → aggregator → post (inline) → shadow record

## Configuration

Settings are layered, highest precedence first: environment (`CODE_CHECK_<SECTION>__<KEY>`, for example `CODE_CHECK_REVIEW__AUTO_APPROVE=true`), the repository's `.code-check.toml`, `~/.config/code-check/config.toml`, then the defaults below. Unknown keys and wrong types in files are errors.

```toml

base_branch = "auto"           # auto = the repository's default branch
remote = "origin"
state_dir = "~/.local/share/code-check/state"

[review]
auto_approve = false           # true: approve only when there are no Critical or Warning findings
max_files = 80                 # larger changes are split into chunks, never skipped
max_chunk_chars = 120000
max_inline_comments = 25       # the rest goes into the review summary
ignore = ["**/*.lock", "dist/**"]

max_prs_per_iteration = 5
repos = []                     # empty = every repository you have access to

[models]
aggregator = "opus"
language_experts = "haiku"
reviewers = "sonnet"           # architect, pragmatist, skeptic
deep = "sonnet"
[models.per_language]          # for example: rust = "sonnet"

[deep_reviewer]

command = ""

[shadow]
enabled = true

[address]
test_command = ""              # run before every push; a failure blocks the push

[run_pr]

|---|---|
| Aggregator | Opus |
| Architect, pragmatist, skeptic | Sonnet |
| 15 language experts | Haiku 4.5 |

The risk is recall: the aggregator cannot recover a bug that nobody reported. Use `models.per_language` to move a language up a tier, and use shadow data to see which ones need it.

## Loops

Run the skills under Claude Code's `/loop`:

```text
/loop 15m /code-check:review-pr          # teammates' PRs awaiting your review
/loop 10m /code-check:babysit-pr         # your PRs: new comments and failing checks
/loop 2m /code-check:review-local        # your working tree, only reviewed again when it changes
```

Each iteration lists the PRs with something new (no LLM), takes at most `loop.max_prs_per_iteration`, and runs each one in its **own headless `claude -p` process, one after another**. Your session only sees a one-line summary per PR, so its context does not fill up. A PR that failed is not retried until it changes. An iteration that starts while the previous one still runs is skipped.

## Safety

- Never force-pushes. Pushes happen only after the configured `address.test_command` passes and only when the remote branch has no commits you lack.
- Refuses to run `address-comments` on a working tree with uncommitted changes, and works in an isolated worktree when you are not on the PR branch.
- Fork-based PRs are reviewed but cannot be pushed to in Phase 1.
- A thread you pushed back on is never resolved by the tool; the reviewer resolves it.
- A review is never approved if the PR is a draft, if any reviewer failed or returned invalid output, or if the PR head moved while the review ran. If GitHub rejects an inline anchor, the findings are posted in the review body instead of being lost.
- Every run first fetches the latest remote base and compares against `<remote>/<base>`, not your local base branch. If the fetch fails the output says "base may be stale".

## Shadow mode

Use it first alongside human reviewers. It does not change behavior; it records what the tool did so human feedback can improve the skills and become a golden evaluation set.

Everything is written (secrets scrubbed) as JSONL under `shadow.store`: the run, every reviewer finding, which ones the aggregator kept, what was posted, the decision, and the verdict for every comment `address-comments` evaluated.

```bash
code-check shadow collect --all                       # later: record what humans did with each comment
code-check shadow export-golden --out golden.jsonl    # auto-labelled examples (confirmed, disputed, misses)
```

`collect` records resolved or outdated threads, human replies and reactions, and human comments the tool never raised. Findings nobody reacted to are false-positive candidates; human comments with no matching finding are misses. Labels are marked `auto` for a human to review.

## Extending

**A new code host.** Implement the `Provider` protocol in `src/codecheck/providers/base.py` (about a dozen methods that return the dataclasses in `models.py`), register it in `providers/__init__.py`, and run the shared contract suite against it by subclassing `ProviderContract` in `tests/providers/contract.py`. Nothing outside `providers/` needs to change. GitHub uses the `gh` CLI; GitLab (`glab`) and Bitbucket are planned for Phase 2.

**The deep reviewer.** Enable `[deep_reviewer]` and give the `deep-reviewer` agent access to your MCP tools, memory or retrieval system. If it is disabled, missing or fails, the panel runs without it.

**Agents.** Prompts and defaults live in `src/codecheck/agentgen.py`; `agents/` is generated from it and a test fails if they drift.

## Troubleshooting

Start with `code-check doctor` (or `npx code-check doctor`).

| Symptom | Fix |
|---|---|
| `gh auth` fails | `gh auth login`, or set `GH_TOKEN` for unattended runs |
| "no changes against base" | Nothing differs from `<remote>/<base>`; commit or edit something, or check `base_branch` |
| "already reviewed" / "unchanged since last review" | Nothing changed since the last run; pass `--force` to `precheck` to review anyway |
| "base may be stale" | The fetch failed (offline or no access); results compare against the last fetched base |
| "run this from a clone of OWNER/REPO" | `review-pr` needs a local clone of the PR's repository |
| A loop does nothing | It only acts on PRs with something new; check `code-check list-work --mode review` |
| Python is older than 3.14.10 | Upgrade (`brew upgrade python@3.14`, `uv python install 3.14`) |
````
