# 0059 A preference verdict counts as a dispute for guidance learning
Status: accepted 2026-11-26
Decision: In guidance evidence a finding answered with the preference verdict counts as disputed, like incorrect, unless a person raised the point or it is security. The golden export is unchanged.
Why: A true finding that was not worth acting on gave the loop no signal; the verdict already says taste. Declining it twice in two PRs now makes a category proposable.
Rejected: A new verdict name, which spreads to the skills and the shadow schema; changing the shared labeller, which would relabel the golden set.
